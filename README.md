# 💻 Mahesh | Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website built with **HTML5**, **CSS3**, and **JavaScript**. Designed to showcase my technical skills, personal projects, education background, and contact details.

![Portfolio Preview](images/project1.jpg) <!-- Optional: Replace with a preview image or screenshot -->

---

## ✨ Features

- **Responsive Design:** Seamlessly adapts across desktop, tablet, and mobile displays.
- **Dark / Light Theme Toggle:** Allows visitors to switch between light and dark modes according to their preference.
- **Scroll Reveal Animations:** Interactive smooth scrolling and scroll-triggered animations powered by `IntersectionObserver`.
- **Form Validation:** Client-side JavaScript validation for the contact section to ensure proper inputs.
- **Clean Typography & Styling:** Modern UI layout with interactive hover states and balanced spacing.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content organization.
- **CSS3:** Custom styling, CSS Variables, Flexbox, Grid, and media queries.
- **JavaScript (ES6):** DOM manipulation, theme toggling, menu interaction, and form handling.
- **Font Awesome:** Vector icons for social links and action buttons.
- **Google Fonts:** Clean web typography using the *Inter* font family.
